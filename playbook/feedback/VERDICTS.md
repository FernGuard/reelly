# Verdicts

This file intentionally contains no real projects, people, accounts, or performance data.

Use one line per reviewed deliverable:

```text
YYYY-MM-DD <project>/<deliverable> KEEP|KILL|FLAW because <reason>
```

Keep private or client-specific verdicts outside a public checkout. To use a different file, point your own workflow at a private copy or replace this template locally without committing it.
