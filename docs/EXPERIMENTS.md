# Experiments

This directory documents reproducible experiment designs, not private outcomes.

## Comparing editor-brain providers

1. Run both providers on the same cached analysis bundle and candidate windows.
2. Render outputs under neutral identifiers.
3. Have reviewers score each output without knowing the provider.
4. Compare keep rate, preference on matched windows, cost, and failure modes.
5. Store real footage, identities, prompts, costs, and verdicts outside the public repository.

Do not publish client data or provider credentials with an experiment report.
